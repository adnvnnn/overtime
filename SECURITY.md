# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository, or contact the repository owner privately if private reporting is unavailable.

Include the affected component, impact, and steps to reproduce where safe. Please allow time for investigation and a fix before public disclosure.

## Scope and deployment

This repository is a demo application, not a production-ready commerce platform. It has no integrated SMS or payment provider. Do not deploy it with demo credentials, development settings, or a database containing real customer information.
